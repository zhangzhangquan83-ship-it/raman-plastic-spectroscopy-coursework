# 课程作业完整运行说明

最终整合版v2.0.0，2026-11-16。下列相对路径均以解压后的项目根目录为起点。本说明区分查看、重新执行展示、核对保存结果、模型推理和从零训练，避免误把“再次读取结果”当成“重新训练”。

## 1 选择适合的包

| 能力 | 轻量提交包/仓库文本文件 | 完整复现包 |
| --- | --- | --- |
| 打开Notebook保存输出、离线HTML和Word | 支持 | 支持 |

完整包是单独可用的全量整合包，不需要再下载v1和补充增量包。两包均不附原`data/raw/` CSV，可按`data/manifest.json`文件ID、原始URL和MD5重取。**重下数据不会恢复历史模型权重**；要复核这批精确冻结模型，应使用完整包。

## 2 环境

已执行训练环境为Python3.12、PyTorch2.8.0+cu128。原训练设备为RTX3090；首阶段补训与旧六图补测设备为RTX3050 Ti Laptop GPU。已有可用CUDA版PyTorch时保留原构建；`requirements.txt`故意不包含torch。

常规依赖锁定为numpy2.5.4、pandas3.0.1、scipy1.18.1、scikit-learn1.9.1、matplotlib3.11.2、joblib1.6.0、nbformat5.11.1、nbclient0.11.0、nbconvert7.17.2和ipykernel7.4.0，以根目录文件为准。安装环境与当前电脑环境隔离。

Linux/macOS创建环境：

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
```

Windows PowerShell创建环境：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
```

Windows若不激活环境，把以下命令中的`python`替换为`.\.venv\Scripts\python.exe`。仅展示不需要torch。需要GPU训练时可优先使用已经配好的兼容PyTorch基础环境；如需新装本作业记录的GPU构建：

```bash
python -m pip install torch==2.8.0 --index-url https://download.pytorch.org/whl/cu128
python -c "import torch; print(torch.__version__, torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

常规Python依赖优先使用清华镜像；GPU版torch单独从其专用源安装，防止装成CPU构建。CUDA运行依赖与驱动需兼容。同种子不保证跨硬件和软件版本逐位相同，反序列化模型优先沿用记录的scikit-learn版本。

## 6 从零重训原首轮与原开发CV

当前交付结果全部完成，无需为交作业重新租云机。若另做训练复现，使用新目录，复制代码、配置、data及extension_study/data与protocol；**不要复制原`results/`或`extension_study/results/`**，不要删除交付目录的原结果。`data/raw/`若不存在，准备脚本会按manifest取得原CSV并校验MD5。

在Linux/WSL等具有bash且已配GPU环境的独立目录运行：

```bash
# 首轮：固定训练/验证/测试、传统模型、3增强CNN和1无增强CNN
python run_frozen_experiment.py
# 开发CV：75次神经拟合与9组传统基线
python extension_study/src/run_cloud_study.py
python extension_study/src/audit_study_results.py --root .
python extension_study/src/summarize_study.py --root .
```

首轮wrapper调用`bash run_cloud.sh`，原生Windows PowerShell不能直接替代该bash流程。两个wrapper分别记录`results/cloud_execution.json`和`extension_study/results/cloud_extension_execution.json`；只跑底层训练器不会自动生成同样的回执。wrapper名称中的cloud描述历史执行背景，不会创建、启动或关闭实例，也不提供云平台计费控制。

历史首轮wrapper会优先把`/root/miniconda3/bin`加入PATH。如果该目录存在，即使外层已激活其他venv，底层裸`python`也可能使用该Miniconda解释器；请确保该环境安装齐全依赖并使用匹配的GPU版PyTorch。原冻结wrapper保持不变。

已有正式首轮会拒绝覆盖。扩展底层runner校验并跳过同配置的完成run，中断run从epoch1开始；没有保存精确恢复训练所需的优化器与全部随机状态。`best.pt`为最佳验证checkpoint，不是完整断点续训状态。

原首轮神经训练最多80轮、patience12、batch256，种子42/43/44；开发研究最多120轮、patience18，种子101/202/303。两者均AdamW、lr0.001、weight_decay0.0001，按验证宏F1早停；详细配置以各run metadata和冻结计划为准，不能把第二阶段参数套回首阶段。

## 7 重做新增7拟合和36冻结推理

要重做**本次新增实验**，使用完整包的独立副本，保留原主数据、原首轮全部结果、原扩展全部模型/结果/协议及补充源码、计划；创建副本时不复制`supplemental_study/results/stage1/`和`supplemental_study/results/stage2_frozen_holdout/`，让新增输出从空目录开始。保留交付原件。

```bash
# 新增RF1次、MLP3种子、ResNet3种子；全部完成后再统一评价
python supplemental_study/src/run_stage1_supplement.py --root . --phase train --device cuda --cpu-threads 8
python supplemental_study/src/run_stage1_supplement.py --root . --phase evaluate --device cuda --cpu-threads 8 --prediction-batch-size 128
python supplemental_study/src/summarize_stage1_supplement.py --root .
# 已有补测计划只核对一致性，不改计划；然后对36个既有权重推理
python supplemental_study/src/evaluate_stage2_frozen_holdout.py --root . --freeze-plan
python supplemental_study/src/evaluate_stage2_frozen_holdout.py --root . --device cuda --cpu-threads 8
python supplemental_study/qa/audit_supplement_results.py --root . --stage all
```

首阶段新增MLP/ResNet种子42/43/44，与原CNN相同增强、80轮上限、patience12；RF固定300树、leaf2、balanced_subsample、random_state101。原验证仅13类有真值支持，最佳epoch按这些支持类宏F1选取，权重选择后不将验证并回训练重拟合。无增强CNN只留在13运行明细，不混进增强CNN主表。

第二阶段复用原核心27神经＋9传统模型，不在28开发图上重新拟合、不集成、不挑最好折或种子。所有模型独立预测同一批5,425谱。已有完成回执时校验后返回，未完成输出目录则拒绝覆盖；不应为了重新运行而篡改计划。

第二阶段计划锁定的是历史权重的**精确字节**。如果从零重训原CV，硬件、浮点或序列化差异可能改变权重哈希，即使配置和指标接近，也不能直接冒充原冻结模型补测。应另立重训研究与来源记录，不修改当前计划绕过身份核验。
