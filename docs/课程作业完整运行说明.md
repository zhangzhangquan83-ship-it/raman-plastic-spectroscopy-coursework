# 大规模拉曼成像光谱的塑料分类与跨图评价

本项目已完成真实RTX3090 GPU训练、正式六图测试和追加的冻结开发研究。课程展示入口为`扩大版_数据与实验展示.ipynb`，离线预览为`扩大版展示预览.html`；两者包含实际执行输出和嵌入图表。主讲10分钟，附录供5分钟问答查阅。

提供两个用途不同的包：`拉曼塑料识别_提交版.zip`保留展示、代码协议、全部预测CSV、日志、指标、元数据及数据获取说明，省略大NPZ、权重和概率矩阵，可直接查看保存输出；`拉曼塑料识别_完整复现包.zip`另含两套处理NPZ及所有权重/概率，支持直接从头执行分析、checkpoint复核与校验。两个包都不重复附源raw CSV。下列直接重跑命令以完整包为前提；提交版须先获取/重建缺失数据与权重，或改用完整包。

## 实际完成的工作与两类结论

第一阶段使用RaMPI的34图、33,119条像素谱、15类（14塑料＋blank）。固定22/6/6图划分，训练20,968、验证5,752、测试6,399像素。验证缺PU、Sil，宏F1平均13类；测试15类齐全。PCA64＋线性SVM测试准确率72.53%、宏F1 0.5873；增强CNN三种子测试准确率70.50% ± 0.58%、宏F1 0.5725 ± 0.0181。±为同一测试集上的训练种子标准差，不能挑最好种子当作整体表现。原六张测试图及首轮结果在追加实验前后SHA256完全一致。

第二阶段只使用原28张开发图，按预先冻结的“开发图覆盖至少3图”规则得到12共同类、25,541像素；排除PC、PU、Sil的1,179像素。采用3外折、每折内验证、3训练种子；完成75次神经训练、9组传统基线、实际3769个训练epoch。每折先平均种子，再对3折求均值和折间标准差。两阶段类别与评价总体不同，不能直接以分数差宣称新增方法提高了原15类测试性能。

## 进一步分析与真实工作量

已完成CNN/MLP/1D-ResNet架构对照、余弦/PCA64线性SVM/300树随机森林基线、增强与类别损失配对消融、四种预处理变体、约60%/80%/100%按图嵌套学习曲线，以及高斯扰动敏感性与置信度校准。100%学习曲线复用核心CNN，未重复计工作量。全部75次神经配置和9组基线在`extension_study/protocol/experiment_plan.json`冻结。

预处理变体全部关闭增强，并与每折默认预处理的noaug CNN seed101配对；不与增强默认模型混作一组。修订发生于任何新增拟合之前，理由与记录见`extension_study/protocol/plan_revision.md`。模拟加噪在SNV输入空间进行，不代表真实仪器信噪比。校准为评价，未在外折拟合温度或决策阈值。

实测神经run耗时合计1735.3秒；它不等于包含安装、传输、准备与空闲时间的实例计费时长。没有将“已充值50元”“可用一天”当成必须花完预算的目标。实际账单需在平台核对。

## 从数据到研究结果的复现

`data/manifest.json`保留开放源地址、文件ID和MD5；完整复现包提供处理后NPZ，两种包都保留行号与划分协议。源数据DOI [10.5683/SP3/8UQQQN](https://doi.org/10.5683/SP3/8UQQQN)，CC BY4.0；数据论文 [10.1038/s41597-026-07103-8](https://doi.org/10.1038/s41597-026-07103-8)。作者署名及计数差异详见`数据来源与研究边界.md`。

```bash
# 校验原始处理数据与冻结划分
python src/prepare_data.py --reuse-processed
python extension_study/src/split_study.py --verify-only
# 本包已含扩展NPZ，按审计哈希复用；去掉--reuse可重新获取开放CSV并处理
python extension_study/src/prepare_study_data.py --reuse
# 按同一计划拟合；完成的run校验哈希后复用，未完成run从头拟合
python extension_study/src/run_study.py --device cuda
# 独立numpy审计；从保存预测重算指标、重画8幅扩展图
python extension_study/src/audit_study_results.py --root .
python extension_study/src/summarize_study.py --root .
# 从头执行展示，不训练模型
python -m jupyter nbconvert --execute --to notebook --inplace 扩大版_数据与实验展示.ipynb
python -m jupyter nbconvert --to html --template classic 扩大版_数据与实验展示.ipynb
```

当前交付保留原测试结果冻结，不再运行首轮evaluate来挑参数。以上命令用于复核原包或补全任务，会校验并跳过已经完成的run，因此再次执行不等于全部重新训练。

从零复现时新建独立目录，仅复制`src/`、`extension_study/src/`、`extension_study/protocol/`、`data/`、`extension_study/data/`、`requirements.txt`、`run_cloud.sh`及`run_frozen_experiment.py`，不要复制任一`results/`。在新目录执行：

```bash
# 首轮wrapper会准备/校验数据和GPU，执行固定脚本并记录首轮云回执
python run_frozen_experiment.py
# 扩展wrapper复用已有开发NPZ（缺失时获取28图），记录原始结果前后SHA及扩展回执
python extension_study/src/run_cloud_study.py
python extension_study/src/audit_study_results.py --root .
python extension_study/src/summarize_study.py --root .
```

两个wrapper分别生成`results/cloud_execution.json`和`extension_study/results/cloud_extension_execution.json`，审计和展示会使用这些回执。根wrapper中的历史初始包哈希用于注明最初冻结来源；本次复现实际数据和源码另记SHA，不能将该历史哈希当成当前ZIP哈希。仅运行底层`bash run_cloud.sh`或`run_study.py`会得到模型数值产物，但不会自动补齐两份回执。

首轮脚本会拒绝覆盖已有正式run。无NPZ时wrapper按公开manifest获取并处理数据；扩展训练未实现逐epoch恢复优化器状态，不能把best.pt称作精确断点续训。不要删除或覆盖原交付结果来重新训练。
