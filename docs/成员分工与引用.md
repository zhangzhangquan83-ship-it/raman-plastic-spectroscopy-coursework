## 代码、算法与依赖

数据发现参考[ml-lab-htw/raman_data](https://github.com/ml-lab-htw/raman_data)，本扩大版直接从Borealis取原CSV；未复制该GitHub项目的模型/加载器，也未使用第三方预训练神经权重。

本作业神经网络从随机初始化训练，架构与执行代码在`src/models.py`和`extension_study/src/study_models.py`。余弦类中心、PCA64＋LinearSVC、随机森林、MLP、1D-CNN和1D-ResNet为通用算法家族，不能声称为本组首创。所用实现依赖如下，实际版本见`requirements.txt`与各run metadata：

| 工具 | 用途 | 官方项目 |
| --- | --- | --- |
| NumPy、pandas | 数组、数据表、独立指标复算 | [NumPy](https://numpy.org/)、[pandas](https://pandas.pydata.org/) |
| SciPy | SG平滑等科学计算 | [SciPy](https://scipy.org/) |
| scikit-learn、joblib | PCA、LinearSVC、随机森林、模型序列化 | [scikit-learn](https://scikit-learn.org/)、[joblib](https://joblib.readthedocs.io/) |
| PyTorch | 从随机初始化训练神经模型与推理 | [PyTorch](https://pytorch.org/) |
| Matplotlib | 科学图表与矢量导出 | [Matplotlib](https://matplotlib.org/) |
| Jupyter/nbformat/nbclient/nbconvert | 可复现展示、保存执行输出和HTML | [Jupyter](https://jupyter.org/) |

代码许可、数据许可和依赖许可应分别遵守。项目的开源声明不代表获得原始数据的独占权。
